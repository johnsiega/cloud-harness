# One-click draft pull request: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A finished run on a repo the owner listed in `PR_REPOS` gets an **Open draft PR into owner/repo** button. One click pushes `harness/<runId>` to that same repo and opens a **draft** pull request into its default branch. Every other run keeps v1's **Push to branch** exactly as it is.

**Architecture:** No refactor of `api/patch-delivery.ts`. Its `pushBranch` already does clone, apply and push with the token only in `GIT_CONFIG_*`, so it is called with `sourceUrl === targetUrl === run.request.repoUrl` and `token = GIT_PR_TOKEN`. New modules:
- `api/repo-allowlist.ts`: one shared URL to `owner/repo` normaliser, used by the server and the UI.
- `api/github-pr.ts`: a GitHub REST client with injected `fetch`, plus pure title and body builders.

A new route, `POST /runs/:id/pr`, combines them. `push-state.ts` gains a `pushMode` and PR labels. `PushControl` picks the endpoint.

**Tech Stack:** Node 22 (TypeScript run directly, `node:test`), Hono, React 19 + Vite, GitHub REST API (`api.github.com`, version `2022-11-28`), git.

**Spec:** [`docs/superpowers/specs/2026-11-25-one-click-draft-pr-design.md`](../specs/2026-11-25-one-click-draft-pr-design.md)
**Depends on:** [piece 1 plan](2026-11-25-per-run-test-command-plan.md), fully shipped (Task 8 green). The PR body reads `test_result.skipped`, and the real check needs goats to end `done`.

## Global Constraints

- TEST FIRST in every code task. Write the tests and a stub, then do a red run where every failure is an assertion. Then **stop at the "tests approved" gate** until the user writes "tests approved". Only then implement.
- Every real-AWS step and every write to GitHub is its own **[go]** gate. The real draft PR on `johnsiega/goats-hsw-rag-chatbot` is a public write.
- Every push is public. Scan the staged or pushed diff for `sk-or-`, `github_pat_`, `AKIA`, 12-digit account ids, the user's email, and `C:\Users` paths. Never commit `.env`. After each push, run `gh run watch` and report.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **I never read, print or create tokens.** The user creates `GIT_PR_TOKEN` and adds it and `PR_REPOS` to `.env` themselves.
- `PR_REPOS=owner/repo,owner/other`: exact match on `owner/repo`, case-insensitive. It is server config only, and no request can choose its target.
- `GIT_PR_TOKEN`: a fine-grained token limited to those repos with **Contents: write** and **Pull requests: write**. It is separate from `GIT_PUSH_TOKEN`.
- The feature is off unless both are set. When it is off, the UI and every existing response shape are exactly as in v1.
- Draft only. Never merge, never mark ready, never open automatically. One PR per run. Branch `harness/<runId>`, never forced.
- Title: `harness: ` plus the first 60 characters of the task. The body holds the task, run id, model, test outcome and "Generated by Cloud harness. Review before merging." Everything goes through the redactor.
- Error mapping (spec): 403 "the token lacks permission for this repo", 404 "repo or token scope is wrong", 422 "a pull request already exists or there is nothing to compare", network "could not reach GitHub". No message contains the token.
- Baseline before Task 1: piece 1 is merged, `npm test` is green, and CI is green.

```ts
// api/repo-allowlist.ts
// Which repos may receive a draft PR (PR_REPOS). Exact owner/repo, case-insensitive. Shared by the server and the UI.
const SLUG = /^[a-z0-9][\w.-]*\/[\w.-]+$/;
const REPO_URL = /^https:\/\/github\.com\/([A-Za-z0-9][\w.-]*\/[\w.-]+?)(?:\.git)?$/;

export function repoSlug(url: string): string | null {
  const m = typeof url === "string" ? REPO_URL.exec(url) : null;
  return m ? m[1].toLowerCase() : null;
}

export function parseRepoList(raw: string | undefined): string[] {
  return [...new Set((raw ?? "").split(",").map((s) => s.trim().toLowerCase()).filter((s) => SLUG.test(s)))];
}

export function isAllowed(url: string, repos: readonly string[]): boolean {
  const s = repoSlug(url);
  return s !== null && repos.includes(s);
}
```

export interface GithubPrs {
  defaultBranch(slug: string): Promise<GhResult<string>>;
  openDraft(i: { slug: string; head: string; base: string; title: string; body: string }): Promise<GhResult<{ number: number; url: string }>>;
}

const API = "https://api.github.com";
const SLUG = /^[A-Za-z0-9][\w.-]*\/[\w.-]+$/;
const BRANCH = /^[\w./-]+$/;
const FAIL: Record<number, [PrFailure, string]> = {
  401: ["pr_unauthorized", "GitHub rejected the PR token (invalid or expired)"],
  403: ["pr_forbidden", "the token lacks permission for this repo (needs Contents and Pull requests: write)"],
  404: ["pr_not_found", "repo or token scope is wrong (GitHub answered 404)"],
  422: ["pr_unprocessable", "a pull request already exists or there is nothing to compare"],
};
const fail = (reason: PrFailure, error: string) => ({ ok: false as const, reason, error });
const httpFail = (status: number) => (FAIL[status] ? fail(...FAIL[status]) : fail("pr_failed", `GitHub answered HTTP ${status}`));
const unreachable = fail("pr_unreachable", "could not reach GitHub");

export function createGithubPrs(o: { token: string; fetch?: FetchLike; timeoutMs?: number }): GithubPrs {
  const doFetch: FetchLike = o.fetch ?? ((url, init) => fetch(url, init));
  const call = async (path: string, body?: unknown) => {
    try {
      return await doFetch(API + path, {
        method: body === undefined ? "GET" : "POST",
        headers: {
          Authorization: `Bearer ${o.token}`, Accept: "application/vnd.github+json", "X-GitHub-Api-Version": "2022-11-28", "User-Agent": "cloud-harness",
          ...(body === undefined ? {} : { "Content-Type": "application/json" }),
        },
        ...(body === undefined ? {} : { body: JSON.stringify(body) }),
        signal: AbortSignal.timeout(o.timeoutMs ?? 15_000),
      });
    } catch { return null; } // network error or timeout; the exception text is never used
  };
  return {
    async defaultBranch(slug) {
      if (!SLUG.test(slug)) return fail("pr_failed", "invalid repo name");
      const r = await call(`/repos/${slug}`);
      if (!r) return unreachable;
      if (r.status !== 200) return httpFail(r.status);
      const b = (await r.json().catch(() => null))?.default_branch;
      return typeof b === "string" && BRANCH.test(b) ? { ok: true, value: b } : fail("pr_failed", "GitHub did not report a default branch");
    },
    async openDraft(i) {
      if (!SLUG.test(i.slug)) return fail("pr_failed", "invalid repo name");
      const r = await call(`/repos/${i.slug}/pulls`, { title: i.title, head: i.head, base: i.base, body: i.body, draft: true });
      if (!r) return unreachable;
      if (r.status !== 201) return httpFail(r.status);
      const j = await r.json().catch(() => null);
      const ok = Number.isInteger(j?.number) && j.number > 0 && typeof j?.html_url === "string" && j.html_url.startsWith("https://github.com/");
      return ok ? { ok: true, value: { number: j.number, url: j.html_url } } : fail("pr_failed", "GitHub's answer did not describe a pull request");
    },
  };
}

export function describeTests(events: TraceEvent[]): string {
  const t = events.filter((e) => e.type === "test_result").at(-1);
  if (!t || t.type !== "test_result") return "not reported";
  if (t.skipped) return `not run (${t.skipped})`;
  return t.exitCode === 0 ? "passed" : `failed (exit ${t.exitCode})`;
}

export function buildPrText(o: { task: string; runId: string; model: string; tests: string }): { title: string; body: string } {
  // A fence longer than any ~ run in the task: inside it, @mentions don't notify and markdown doesn't render.
  const fence = "~".repeat(Math.max(3, ...(o.task.match(/~+/g) ?? []).map((s) => s.length + 1)));
  return {
    title: "harness: " + o.task.replace(/\s+/g, " ").trim().slice(0, 60),
    body: [`Task:`, ``, `${fence}text`, o.task, fence, ``, `- Run: \`${o.runId}\``, `- Model: \`${o.model}\``, `- Tests: ${o.tests}`, ``, `Generated by Cloud harness. Review before merging.`].join("\n"),
  };
}
